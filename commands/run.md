description: Запустить автономный прогон по плану до конца или до серьёзного
---

Работай в режиме `run` над текущей задачей (правила — скилл controlled-work):
иди по плану без пауз, останавливайся только на серьёзном.

- Если у задачи есть папка спеки, запиши `mode: run` в front-matter `index.md`.
- Код — через субагента `general`, главная сессия только координирует.
- Гейт на каждый пункт (если есть спека), ревьюер — субагент `spec-reviewer` (выдержки спеки текстом).
- Строка на закрытый пункт, экран на закрытый этап; при остановке — блок «где встал / почему / варианты / что рекомендую».
