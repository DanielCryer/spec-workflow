Работай в режиме `run` над текущей задачей (правила — скилл controlled-work):
по плану без пауз, остановка только на серьёзном.

- Если у задачи есть папка спеки, запиши `mode: run` в front-matter `index.md`.
- Код — через субагента `general`, главная сессия только координирует.
- Гейт на каждый пункт (если есть спека), ревьюер — `spec-reviewer` с выдержками текстом. Строка на закрытый пункт, экран на этап; при остановке — «где встал / почему / варианты / что рекомендую».
