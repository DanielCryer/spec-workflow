Работай в режиме `step` над текущей задачей (правила — скилл controlled-work):
один пункт плана, затем гейт и ревьюер, карточка в `notes.md`, стоп до ответа
пользователя.

- Код в главной сессии не пиши — только субагент `general` на один пункт.
- Гейт: `scripts/spec_check.py` из скилла `spec-driven-development` (запуск через `python3`, на Windows `py`). Ревьюер: субагент `spec-reviewer`, выдержки спеки текстом + репозиторий + дифф.
