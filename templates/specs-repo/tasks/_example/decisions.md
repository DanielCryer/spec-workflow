# Решения

Сквозные решения задачи: те, по которым работает кто-то вне этапа, или те, что переживают этап. Решения этапа живут в `stages/<slug>/decisions.md` и нумеруются кодом этапа (`Dex.1`).

**Последняя ревизия:** 2026-01-01

## Действующие решения

- **D1** — что решили, одной строкой.

## D1. Формат записи решения

- **Контекст:** зачем вообще выбор, 1–2 строки без пересказа кода.
- **Решение:** что теперь считается правильным.
- **Альтернативы:** реально рассмотренные и причина отказа, не было — `—`.
- **Последствия:** только «что теперь нельзя делать иначе».
- **Статус:** действует
- **Ссылки:** `<репозиторий>@<коммит>`, `<путь>.cpp:<строка>`, PR
- **Правило:** rules/masks.md — путь от корня папки задачи, только если решение стало правилом
