# Спеки — правила для агента

Это репозиторий артефактов, не кода. Структура — в `README.md`, правила записей — в скилле `spec-driven-development` (`references/formats.md`). Здесь только вход.

- Начинай с `TASKS.md`, если известен лишь ID. Иначе сразу `tasks/<папка>/index.md`.
- `index.md` — единственный обязательный файл. Нет остальных — это lite-режим, а не незаполненная спека.
- `decisions.md` читай по сводке и заголовкам, полный текст — по номеру (`grep '^## D43'`). Журнал целиком не читай: он растёт.
- `problems.md` — до того, как чинить в затронутой области.
- `analysis/` и `sources/` — собранные данные и внешние документы. Не канон: решение не должно читаться только через них.
- `archive/` — история закрытых шагов. По умолчанию не читай: только по ссылке из этапа или журнала.
- `notes.md` и `todo.md` — не решения, не цитировать.
- Секреты и внутренние адреса с доступами сюда не попадают.
